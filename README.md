# \# Minimal VM Browser (极简纯沙箱浏览器虚拟机)

# 

# 这是一个将 \*\*Linux Kernel + 极简无壳 Chromium + 用户态网络栈(SLIRP) + 精简版 QEMU\*\* 深度裁剪并融合成\*\*单个物理体积约 150MB\~250MB 的 Windows .exe 应用程序\*\*的系统级开源项目。

# 

# \## 🎯 核心特性

# 

# 1\. \*\*极致体积精简\*\*

# &#x20;  - 摒弃了数十 GB 传统的常规 Linux 桌面发行版镜像或 Windows 虚拟机镜像。

# &#x20;  - 采用定制的极精简 Linux 内核（裁剪掉绝大部分无用硬件驱动，仅保留虚拟化必需），体积约 `5MB`。

# &#x20;  - 基于 BusyBox 配合魔改无 X11/GPU 依赖、纯 CPU 软渲染（或走通过 VirtIO-GPU 映射）的无头/单窗口 Chromium 构建最小 Rootfs (`\~120MB`)。

# 2\. \*\*零痕迹网络沙箱 (SLIRP 用户态 NAT)\*\*

# &#x20;  - 虚拟机内部网络栈完全在 QEMU 进程的用户态内存空间中通过软件协议栈实现（类似于应用层代理的 NAT 转换）。

# &#x20;  - \*\*完全不在宿主机上创建任何虚拟网卡，不占用或篡改物理 MAC 地址\*\*，宿主机网络监控无法察觉新的网卡接入。

# 3\. \*\*单 EXE 纯绿独立运行\*\*

# &#x20;  - 通过 C 语言编写高内聚启动器，利用 `objcopy` 将全部固件压缩嵌入 `launcher.exe` 内部。

# &#x20;  - 运行时秒级在宿主机临时隔离目录释放、冷启动拉起、关闭时自动强制销毁擦除所有痕迹。
