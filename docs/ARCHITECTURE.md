## 🔄 启动流程

### 时间线

```
时间    事件                        说明
──────────────────────────────────────────────────────
0ms     程序启动                    EXE 执行

10ms    资源解包                    从 EXE 中提取:
        ├─ vmlinuz                  - Linux 内核
        ├─ initramfs.gz             - 根文件系统
        ├─ qemu-system-x86_64       - 虚拟化器

50ms    临时文件创建                创建 /tmp 中的文件

100ms   QEMU 启动                   启动虚拟机进程
        ├─ 初始化 CPU 模拟器
        ├─ 分配内存 (256-512 MB)
        ├─ 加载内核到内存
        ├─ 配置 virtio 设备

500ms   Linux 内核启动              Linux 接管 CPU

600ms   Init 进程启动               /sbin/init 执行

700ms   挂载文件系统                装载虚拟文件系统
        ├─ /proc
        ├─ /sys
        ├─ /dev
        ├─ tmpfs

800ms   配置网络                    SLIRP 初始化
        ├─ DHCP 获取 IP
        ├─ 配置 DNS
        ├─ 启动网络服务

1000ms  启动应用                    Chromium 进程启动
        ├─ 初始化浏览器引擎
        ├─ 加载扩展
        ├─ 建立监听端口 (9222)

1500ms  就绪                        虚拟机就绪,可接收请求

2000ms  首次网络请求               浏览器发起请求
        └─ DNS 解析 → 建立连接 → 获得数据
───────────────────────────────────────────────────────

总启动时间: 1.5-2 秒 (vs 传统 VM 30-60 秒)
```

### 启动脚本 (/sbin/init)

```bash
#!/bin/sh
# 最小化 init 脚本

# 1. 挂载关键文件系统
mount -t proc proc /proc
mount -t sysfs sys /sys
mount -t devtmpfs dev /dev
mount -t tmpfs tmp /tmp

# 2. 设置基本参数
hostname vm-browser
export PATH=/bin:/sbin:/usr/bin:/usr/sbin

# 3. 配置网络 (由 SLIRP 自动)
# DHCP 已由 QEMU/SLIRP 处理

# 4. 启动必要服务
[ -x /usr/sbin/sshd ] && /usr/sbin/sshd -D &  # 可选

# 5. 启动应用 (Chromium)
exec /opt/chromium/chrome \
    --headless \
    --disable-gpu \
    --disable-sandbox \
    --listen=0.0.0.0:9222 \
    --remote-debugging-port=9222

# 可选: 如需交互
# exec /bin/sh
```

## 🔐 安全特性

### 隔离

```
✓ 进程隔离              - 虚拟机完全独立进程
✓ 文件系统隔离          - /tmp 中的临时文件
✓ 网络隔离              - SLIRP 用户态 NAT
✓ 内存隔离              - QEMU 内存空间
✗ 无完整的 SELinux      - (可选添加)
✗ 无完整的 AppArmor     - (可选添加)
```

### 沙箱

```
Chromium 配置:
  --no-sandbox        禁用 Chromium 沙箱 (已包含)
  --disable-sandbox   (同上)
  
替代方案:
  使用 --enable-features=IsolatedWebApps
  启用现代安全功能
```
